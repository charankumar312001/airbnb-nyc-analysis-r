# 🏙️ Airbnb NYC 2019 Analysis (R Studio Project)

This data analysis project explores Airbnb listings across New York City using the **2019 NYC Airbnb Open Data**. Built in R using R Markdown, the project delivers data-driven insights into rental trends, pricing patterns, neighborhood popularity, and host behaviors.

## 📁 Files Included

- `charan_final_project.Rmd` — Final R Markdown report with code, visuals, and narrative
- `AB_NYC_2019.csv` — The dataset used, sourced from Kaggle

---

## 🔍 Key Insights

- **Brooklyn and Manhattan** dominate in terms of number of listings and average prices.
- **Room type** and **neighborhood group** significantly influence pricing.
- A small number of hosts control a large portion of listings.
